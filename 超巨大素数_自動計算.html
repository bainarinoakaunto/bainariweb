📘 計算方法

1. 0から順番に検査
0 → 1 → 2 → 3 → 4 → … と 1ずつ増やして判定します。

2. BigInt
JavaScriptのBigIntを使用して、 通常のNumberでは扱えない大きな整数を扱います。

3. Miller–Rabin
n - 1 を

n - 1 = 2s × d

に分解し、
ad mod n
および
x ← x² mod n
を使って判定します。

4. 自動保存
計算位置・素数・計算ログなどを localStorageへ保存します。
